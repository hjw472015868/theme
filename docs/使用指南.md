## 📦 GitHub 集成方式

### 为什么使用 GitHub？

- ✅ **版本控制**：完整的 Git 历史记录和标签管理
- ✅ **无需 npm 账号**：不需要发布到 npm 即可使用
- ✅ **快速迭代**：可以快速发布新版本
- ✅ **开源协作**：团队成员可以贡献和审查

### 安装步骤

#### 1. 在项目中安装

```bash
# 安装指定版本（推荐）
pnpm add git+https://github.com/hjw472015868/theme.git#v1.0.0

# 或安装最新版本
pnpm add git+https://github.com/hjw472015868/theme.git
```

#### 2. 配置 package.json

```json
{
  "dependencies": {
    "@km-design/theme-system": "git+https://github.com/hjw472015868/theme.git#v1.0.0"
  }
}
```

#### 3. 安装依赖

```bash
pnpm install
```

### 更新包

#### 更新到最新版本

```bash
# 更新到最新提交
pnpm update @km-design/theme-system

# 或重新安装
pnpm add git+https://github.com/hjw472015868/theme.git
```

#### 更新到指定版本

```bash
# 更新到指定标签版本
pnpm add git+https://github.com/hjw472015868/theme.git#v1.0.1
```

### 在 monorepo 中使用

如果项目是 monorepo，可以在根目录的 `package.json` 中配置：

```json
{
  "pnpm": {
    "overrides": {
      "@km-design/theme-system": "git+https://github.com/hjw472015868/theme.git#v1.0.0"
    }
  }
}
```

## 🚀 UmiJS 项目集成

> ⚠️ **重要提示**：如果是首次集成，强烈建议先阅读 [UmiJS 集成指南](./UmiJS集成指南.md)，包含完整的步骤、常见错误解决方案和验证方法。

### 快速集成

#### 1. 安装包

```bash
# 推荐使用 latest 标签（自动获取最新稳定版本）
pnpm add git+https://github.com/hjw472015868/theme.git#latest

# 或使用固定版本
pnpm add git+https://github.com/hjw472015868/theme.git#v1.0.0
```

#### 2. 导入样式文件 ⚠️ 必须！

```typescript
// app.tsx
import '@km-design/theme-system/index.css'; // ⚠️ 必须导入，否则主题变量不生效！
import { UmiThemeProvider } from '@km-design/theme-system';
```

#### 3. 在 `app.tsx` 中使用

```typescript
// app.tsx
import { UmiThemeProvider } from '@km-design/theme-system';

export function rootContainer(container: React.ReactElement) {
  return (
    <UmiThemeProvider
      defaultTheme="km-base"
      enableStorage={true}
      storageKey="my-app-theme"
    >
      {container}
    </UmiThemeProvider>
  );
}
```

#### 3. 在组件中使用

```typescript
// src/components/Header.tsx
import { useTheme, ThemeSwitcher } from '@km-design/theme-system';

export default function Header() {
  const { currentTheme, switchTheme, availableThemes } = useTheme();

  return (
    <header style={{
      background: 'var(--card)',
      padding: 'var(--spacing-md)'
    }}>
      <div>我的应用</div>
      <ThemeSwitcher />
      <p>当前主题: {currentTheme}</p>
      <div>
        {availableThemes.map(theme => (
          <button key={theme} onClick={() => switchTheme(theme)}>
            {theme}
          </button>
        ))}
      </div>
    </header>
  );
}
```

## 🚀 Next.js 项目集成

```bash
pnpm add git+https://github.com/hjw472015868/theme.git#v1.0.0
```

#### 2. 创建主题包装器（推荐）

```typescript
// theme/theme-wrapper.tsx
'use client';
import { NextThemeProvider } from '@km-design/theme-system';

export function ThemeWrapper({ children }: { children: React.ReactNode }) {
  return (
    <NextThemeProvider
      defaultTheme="light"
      enableStorage={true}
      storageKey="km-flow-theme"
    >
      {children}
    </NextThemeProvider>
  );
}
```

#### 3. 在 `app/layout.tsx` 中使用

```typescript
// app/layout.tsx
import { ThemeWrapper } from '@/theme';

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="zh-CN">
      <body>
        <ThemeWrapper>
          {children}
        </ThemeWrapper>
      </body>
    </html>
  );
}
```

#### 4. 在组件中使用

```typescript
// app/components/Header.tsx
'use client';
import { useTheme, ThemeSwitcher } from '@km-design/theme-system';

            {theme}
```

## 🛠 样式迁移快速通道

> 如果你需要把已有项目（尤其是 Next.js）改造为可联动的主题体系，请配合《[样式迁移指南](./样式迁移指南.md)》执行以下步骤：

1. **入口改造**：确保 `ThemeProvider` 已经包裹根组件，并开启 `ThemeEditor`。
2. **Tailwind 同步**：将 `tailwind.config.js` 的 `colors`、`spacing`、`borderRadius`、`boxShadow` 等映射到 `var(--token)`。
3. **全局样式迁移**：把 `globals.css` / `global.scss` 等文件中的硬编码颜色、间距、阴影改为语义化变量（如 `--background`、`--spacing-md`）。
4. **组件样式迁移**：无论是 CSS Module、styled-components 还是 inline style，都统一改用变量，避免直接写 `#xxxxxx`。
5. **联动验证**：打开主题配置中心调试主题，确认页面各处样式实时响应。

> 💡 建议维护一份“旧值 → 变量”对照表，方便团队协同开发与 Code Review。

## 🎨 使用 CSS Variables

### 在样式文件中使用

```css
/* styles.css 或 styles.less */
.my-component {
  padding: var(--spacing-md);
  color: var(--foreground);
  background-color: var(--background);
  border: 1px solid var(--border);
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-md);
}

.my-card {
  background-color: var(--card);
  border: 1px solid var(--card-border);
  box-shadow: var(--shadow-lg);
}

.my-button {
  padding: var(--spacing-sm) var(--spacing-md);
  color: var(--primary-foreground);
  background-color: var(--primary);
  border-radius: var(--radius-md);
}
```

### 在组件中使用

```typescript
// 内联样式
<div style={{
  backgroundColor: 'var(--background)',
  color: 'var(--foreground)',
  padding: 'var(--spacing-md)',
  borderRadius: 'var(--radius-md)',
}}>
  内容
</div>

// 使用 Tailwind CSS 类名
<div className="bg-background text-foreground p-md rounded-md">
  内容
</div>
```

## ❓ 常见问题

### Q: 如何添加新的预设主题？

**A**:

1. 在 `packages/theme-system/src/presets/` 创建 JSON 文件
2. 在 `src/index.ts` 中导出
3. 在适配器中注册（Next.js 需要在 `nextjs-adapter.tsx` 中静态导入）
4. 重新构建包：`pnpm build`
5. 提交并推送，创建新标签

### Q: 如何自定义主题切换器样式？

**A**:

1. 修改 `packages/theme-system/src/components/ThemeSwitcher.tsx`
2. 重新构建包：`pnpm build`
3. 或创建自己的主题切换器组件，使用 `useTheme` Hook

### Q: 如何禁用主题持久化？

**A**:

```typescript
<UmiThemeProvider
  defaultTheme="km-base"
  enableStorage={false}  // 禁用持久化
>
  {children}
</UmiThemeProvider>
```

### Q: 如何获取主题的特定颜色？

**A**:

```typescript
const { themeConfig } = useTheme();
const primaryColor = themeConfig?.colors?.primary?.[500];
const backgroundColor = themeConfig?.colors?.semantic?.background;
```

### Q: 如何在非 React 组件中使用主题？

**A**:

```typescript
// 使用 CSS Variables（推荐）
const bgColor = getComputedStyle(document.documentElement).getPropertyValue('--background');
```

### Q: 主题切换后样式没有更新？

**A**:

1. 确保使用了 CSS Variables 而不是硬编码的颜色值
2. 检查 Tailwind CSS 配置是否正确
3. 确保 `ThemeProvider` 包裹了所有需要主题的组件

### Q: Next.js 项目中使用主题时出现 SSR 错误？

**A**:

1. 确保 `NextThemeProvider` 在客户端组件中使用（添加 `'use client'`）
2. 确保主题注册在客户端进行（使用 `useEffect`）
