## 1. 主题变量使用规范

### 1.1 颜色变量

✅ **正确使用**：

```typescript
// 使用主题变量
const styles = {
  container: {
    backgroundColor: 'var(--background)',
    color: 'var(--foreground)',
    border: '1px solid var(--border)',
  },
  primaryButton: {
    backgroundColor: 'var(--primary)',
    color: 'var(--primary-foreground)',
  },
};
```

❌ **避免**：

```typescript
// 硬编码颜色值
const badStyles = {
  container: {
    backgroundColor: '#ffffff', // 硬编码
    color: '#333333', // 硬编码
  },
};
```

### 1.2 间距和尺寸

✅ **正确使用**：

```typescript
// 使用主题间距变量
const spacing = {
  small: 'var(--spacing-sm)', // 8px
  medium: 'var(--spacing-md)', // 16px
  large: 'var(--spacing-lg)', // 24px
};
```

### 1.3 圆角变量

✅ **正确使用**：

```typescript
const borderRadius = {
  small: 'var(--radius-sm)', // 4px
  medium: 'var(--radius-md)', // 8px
  large: 'var(--radius-lg)', // 12px
  full: 'var(--radius-full)', // 9999px
};
```

### 2.1 基础组件适配

```typescript

import styled from 'styled-components';

const StyledButton = styled.button`
  padding: var(--spacing-sm) var(--spacing-md);
  border-radius: var(--radius-md);
  background-color: var(--primary);
  color: var(--primary-foreground);
  border: 1px solid var(--primary);
  transition: background-color 0.2s;

  &:hover {
    background-color: var(--primary-hover);
  }

  &:disabled {
    opacity: 0.6;
    cursor: not-allowed;
  }

export const Button = ({ children, ...props }) => {
  return <StyledButton {...props}>{children}</StyledButton>;
};
```

## 3. 暗黑模式适配

### 3.1 使用CSS变量实现主题切换

```css
/* 基础样式 */
:root {
  --background: #ffffff;
  --foreground: #333333;
  --card: #ffffff;
  --border: #e0e0e0;
}

/* 暗黑模式 */
[data-theme='dark'] {
  --background: #121212;
  --foreground: #ffffff;
  --card: #1e1e1e;
  --border: #333333;
}
```

### 3.2 React中的主题切换

```typescript
// ThemeContext.tsx
import React, { createContext, useContext, useEffect, useState } from 'react';

type Theme = 'light' | 'dark';

const ThemeContext = createContext<{
  theme: Theme;
  toggleTheme: () => void;
} | null>(null);

export const ThemeProvider = ({ children }) => {
  const [theme, setTheme] = useState<Theme>('light');

  useEffect(() => {
    const savedTheme = localStorage.getItem('theme') as Theme;
    const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;

    const initialTheme = savedTheme || (prefersDark ? 'dark' : 'light');
    setTheme(initialTheme);
    document.documentElement.setAttribute('data-theme', initialTheme);
  }, []);

  const toggleTheme = () => {
    const newTheme = theme === 'light' ? 'dark' : 'light';
    setTheme(newTheme);
    localStorage.setItem('theme', newTheme);
    document.documentElement.setAttribute('data-theme', newTheme);
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
};

export const useTheme = () => {
  const context = useContext(ThemeContext);
  if (!context) {
    throw new Error('useTheme must be used within a ThemeProvider');
  }
  return context;
};
```

## 5. 常见问题解决方案

### 5.1 主题切换闪烁

**问题**：切换主题时页面闪烁 **解决方案**：在HTML根元素上设置初始主题

```html
<!DOCTYPE html>
<html lang="zh-CN" data-theme="light">
  <!-- ... -->
</html>
```

### 5.2 第三方组件样式不更新

**问题**：第三方组件在主题切换时样式不更新 **解决方案**：使用`useEffect`监听主题变化并强制更新

```typescript
import { useEffect } from 'react';
import { useTheme } from './ThemeContext';

const ThirdPartyComponentWrapper = () => {
  const { theme } = useTheme();

  useEffect(() => {
    window.dispatchEvent(new Event('themeChange'));
  }, [theme]);

  return <ThirdPartyComponent />;
};
```

### 5.3 主题变量未定义

**问题**：某些主题变量未定义导致样式错误 **解决方案**：提供默认值

```css
.element {
  color: var(--foreground, #333333);
  background-color: var(--background, #ffffff);
}
```

## 7. 最佳实践清单

### 7.1 必须遵循的规则

1. **禁止硬编码颜色值**：始终使用主题变量
2. **使用语义化变量名**：如`--primary`而非`--blue-500`
3. **保持层级一致性**：遵循背景层级系统
4. **考虑暗黑模式**：确保所有颜色在亮/暗模式下都可用
5. **添加过渡效果**：为颜色变化添加平滑过渡

### 7.2 代码审查要点

1. 检查是否有硬编码的颜色值
2. 确保所有交互状态都有正确的样式
3. 验证暗黑模式下的可读性
4. 检查响应式设计是否完整
5. 确保第三方组件样式正确覆盖

### 7.3 性能优化建议

1. 使用CSS变量而非JavaScript计算样式
2. 避免过度使用`!important`
3. 按需加载主题变量
4. 使用CSS变量进行主题切换而非动态生成样式
